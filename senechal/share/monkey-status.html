Machine-readable: status.json. Published by realisateur/bin/monkey-watch.sh, which runs on dexter, the VM host — not on monkey. That is the whole point: it can report monkey being down because it does not depend on monkey being up. Account rows come from bin/monkey-status-collect.py, fed to the guest over stdin and run as root, so every row is a live probe of a crontab, a run ledger and a file mode — never a claim copied from a document. ARMED means the account's own crontab holds a dispatch runner; never run means its scheduler ledger is empty, which for an armed account is a finding. An empty account list is never padded with the last healthy world: when the guest is unreachable it stays empty and the verdict says so.
